# Security and privacy

Business Calfin is a local financial decision tool. There is no telemetry or backend account. Files are not encrypted; protect the operating-system account, device and backups. Never upload real business records to public issues.

The renderer is isolated and sandboxed. Main-process file operations validate sender and payload. File imports are untrusted input and cannot execute code. External navigation, new windows and browser permissions are denied.

These measures do not amount to a security certification. The application does not authenticate multiple users, verify bank statements or provide tamper-proof financial records. Treat "reconciled" as a user's declaration.

Report vulnerabilities through GitHub's private vulnerability reporting if it is available for this repository. If it is not available, open a minimal issue asking for a private channel, without an exploit or sensitive data. Do not assume a private reporting feature is enabled.

The Windows executable is unsigned. Check the source, release verification and SHA-256 checksum; do not disable antivirus or operating-system protections to install it. Electron and other dependencies require ongoing maintenance.
